# README — «Игла в стоге сена»

Эта страница — первая: карта файлов, план доработок и правила работы
с ассистентом. Прочитай её прежде, чем открывать остальное.

## Что это

Игра на pygame: в стоге сена спрятана игла. Игрок копает клетки, находит
камни, зверей и ядовитые растения, лечится бинтами и противоядиями,
продаёт сено и покупает улучшения в лавке. Уровни бесконечны: поле
растёт, клетки мельчают, ловушки злее.

## Запуск

```bash
pip install pygame
python main.py
```

## Правила работы с ассистентом

1. Пользователь присылает архив (zip) с игрой.
2. Алиса читает README.md (карта файлов, правила) и PLAN.md — видит
   текущую правку и что уже сделано.
3. Применяется РОВНО ОДНА правка из списка ниже.
4. После каждого шага плана актуализируется карта файлов в README.md —
   всегда, даже если менялся только один модуль.
5. Собирается новый zip и передаётся пользователю ТОЛЬКО как вложение
   к сообщению (не ссылкой на файл в контейнере — она ломается).
   Страховка: пересобирать и сохранять архив на диск сразу после
   каждой успешной партии замен — каждый сохранённый файл
   автоматически прикрепляется к результату вызова инструмента, так
   что обрыв контекста посреди шага не теряет работу.
6. Если вложение или сборка потерялись — прогресс не считается
   потерянным: последний присланный пользователем архив содержит всю
   работу. Сверить BUILD-маркер и воспроизвести шаг по плану.
7. Собранный архив передаётся пользователю ссылку на вложение по его
   идентификатору — до запуска каких-либо тестов; тесты запускаются
   только после одобрения пользователя.
