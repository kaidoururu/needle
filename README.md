# README — «Игла в стоге сена»

Эта страница — первая: карта файлов, план доработок и правила работы
с ассистентом. Прочитай её прежде, чем открывать остальное.

## Что это

Игра на pygame: в стоге сена спрятана игла. Игрок копает клетки, находит
камни, зверей и ядовитые растения, лечится бинтами и противоядиями,
продаёт сено и покупает улучшения в лавке. Уровни бесконечны: поле
растёт, клетки мельчают, ловушки злее.

## Запуск

```bash
pip install pygame
python main.py
```

## Правила работы с ассистентом

1. Пользователь присылает архив с игрой. Ассистент смотрит BUILD-маркер
   в шапке game_config.py и статус в PLAN.md — так видно прогресс.
2. За один архив — ровно одна правка из плана.
3. После каждого шага плана ассистент ОБЯЗАН актуализировать:
   карту файлов выше (если менялись файлы или их ответственность),
   PLAN.md (статус и история версий) и BUILD-маркер в game_config.py.
4. Новый архив ассистент отдаёт сразу в том же сообщении.
