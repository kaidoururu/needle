# PLAN.md — план работ (живёт в архиве, переживает сессии)

## Как работаем

1. Пользователь присылает архив (zip) с игрой.
2. Алиса читает README.md (карта файлов, правила) и PLAN.md — видит
   текущую правку и что уже сделано.
3. Применяется РОВНО ОДНА правка из списка ниже.
4. Собирается новый zip: обновлённые модули + обновлённые README.md,
   PLAN.md и, если нужно, game_map.md.
5. Ссылка на архив сразу в том же сообщении. Пользователь скачивает сразу.
6. После каждого шага плана актуализируется карта файлов в README.md —
   всегда, даже если менялся только один модуль.

## Правило версии

- В шапке game_config.py стоит BUILD-маркер: `# BUILD: v5-N <название шага>`.
- N — номер последнего выполненного шага из плана. По нему Алиса
  мгновенно определяет прогресс без построчной сверки.

## Список правок, которые нужно вносить по одной

1. [ ] Большая лопата копает кругом, а не квадратом. Если энергии не
       хватает на целый рывок в выбранном месте — вообще не копать и
       показать сообщение «Не хватает сил».
       Файлы: game_digging.py (dig_at: форма рывка и проверка силы),
       game_config.py (константы круга).
2. [ ] Прокачка бинтов в лавке: растут и количество в кармане, и объём
       восстанавливаемого здоровья — укус и яд с уровнем становятся
       сильнее, бинты должны поспевать за ними.
       Файлы: game_config.py (BANDAGE_*), game_economy.py (bnd_cost,
       shop_item_info), game_health.py (use_bandage), game_shop.py.
3. [ ] Магнит заменить на «энергетик»: на 10 секунд энергия не тратится
       ИЛИ рывки становятся крупнее (одно из двух — выбрать при
       реализации). Файлы: game_config.py (ENERGY_DRINK_*),
       game_digging.py, game_effects.py, game_drawings.py (иконка),
       game_help.py (текст справки).
4. [x] Меню паузы: кнопки не помещались в рамку — панель выросла
       с 372 до 404 px, кнопки с отступом снизу 26 px, панель не даёт

       game_config.py (настройки кластеров).
