# PLAN.md — план работ (живёт в архиве, переживает сессии)

## Как работаем

1. Пользователь присылает архив (zip) с игрой и этим планом.
2. Алиса читает PLAN.md — видит текущую правку и что уже сделано.
3. Применяется РОВНО ОДНА правка из списка ниже.
4. Собирается новый zip: обновлённые модули + обновлённый PLAN.md.
5. Ссылка на архив сразу в том же сообщении. Пользователь скачивает сразу.

## Правило версии

- В шапке game_config.py стоит BUILD-маркер: `# BUILD: v5-N <название шага>`.
- N — номер последнего выполненного шага из плана. По нему Алиса
  мгновенно определяет прогресс без построчной сверки.
