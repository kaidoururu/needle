# PROJECT.md — паспорт проекта

## Что это

**«Игла в стоге сена»** — игра на pygame: в стоге прячет игла, игрок копает клетки,
находки (камни, звери, ядовитые растения) мешают, бинты и противоядия помогают.
Десять уровней: на каждом поле больше (клетки мельче), а ловушки злее.

- Экран: 720×1280, портретная ориентация, RESIZABLE.
- Язык интерфейса: русский.
- Зависимость: только `pygame` (версия — любая актуальная; для сборки APK см. ниже).

## Точки правды

1. **Репозиторий GitHub — главный источник истины.** Любая правка делается
   от того, что лежит в репо сейчас, а не от старых копий в чате.
2. Оригинал до рефакторинга: `hay.py` (монолит, 1839 строк, класс `Game` с 71 методом).
   Хранится как справочник, запускаем код из модулей, а не из монолита.

## Структура проекта

| Файл | Ответственность |
|---|---|
| `main.py` | Точка входа: `Game().run()` |
| `game_config.py` | Все константы: баланс, вероятности, цены, цвета |
| `game_core.py` | Класс `Game`: наследует все примеси, `__init__`, шрифты, кэши, главный цикл |
| `game_field.py` | Стог: `build_field`, цены клеток, игла, `restart`, `next_level` |
| `game_health.py` | Аптечка: бинты/противоядия, урон зверя, отравление |
| `game_effects.py` | Сообщения, таблички находок, вспышки экрана, соломинки |
| `game_economy.py` | Сторона копания, реген, цены улучшений, `sell`, `buy` |
| `game_ui.py` | HUD: полосы здоровья/сил, кнопки, монеты, `build_ui` |
| `game_drawings.py` | Рисунки находок (камень, растение, зверь, бинт, флакон) и иконки лавки |
| `game_shop.py` | Выдвижная лавка улучшений (6 панелей) |
| `game_help.py` | Выдвижная справка «?» (панель с правилами) |
| `game_screens.py` | Экраны победы и смерти |
| `game_digging.py` | Копание: рывок, ловушки, обработка кликов |
| `game_save.py` | Сохранение/загрузка прогресса: `hay_save.json` |

Подход к нарезке — **примеси (mixin)**: каждый модуль объявляет свой
`SomethingMixin`, а `game_core.py` собирает их в один класс:

```python
class Game(FieldMixin, HealthMixin, EffectsMixin, EconomyMixin,
           UIMixin, DrawingsMixin, ShopMixin, HelpMixin,
           ScreensMixin, DiggingMixin):
```

Поведение идентично монолиту `hay.py` — методы те же, в том же порядке.

## Баланс (что уже решено и не менять без обсуждения)

- Здоровье **само не восстанавливается** — только бинты (`HEALTH_BASE = 100`,
  бинт лечит 30).
- Смерть: теряется **40% монет**, сено и улучшения сохраняются
  (`DEATH_MONEY_KEEP = 0.6`).
- После 10 уровня — бесконечный стог: ловушки +5%/уровень,
  бонус за иглу ×1.25 за уровень. Золотая игла — 1 из 15 стогов, бонус ×5.
- Редкие находки: компас, магнит, клевер (`P_COMPASS`, `P_MAGNET`,
  `P_CLOVER`). Каждые 10 рывков без ловушек — бонус монетами.
- Стога темнее → ловушки чаще, аптечка реже (`TRAP_DARK_MULT`, `BANDAGE_LIGHT_MULT`).
- Игла не даёт находок в своей клетке.
- 10 уровней (MAX_LEVEL), клетка уменьшается с 44 до 12 пикселей.

## Сборка APK

- Способ: **GitHub Actions + buildozer** (рабочий файл — `.github/workflows/build-apk.yml`).
- Локальная сборка под Windows — только через WSL2 (Buildozer под Windows не работает).
- Требования сборки: `Cython<3.0`, `setuptools<71.0.0` (иначе pygame падает на `longintrepr.h`).
- В `buildozer.spec`: `requirements = python3,pygame`, `orientation = portrait`,
  `android.archs = arm64-v8a`, `source.include_exts = py,png,jpg` (без `.md` и лишнего).

## Воркфлоу с AI-ассистентом

1. Пользователь присылает ссылку на публичный репозиторий и задачу.
2. Ассистент читает актуальные файлы из репо, вносит правки, выдаёт архив
   с изменёнными файлами и списком изменений.
3. Пользователь заливает файлы в репо (веб-интерфейс или git), Actions пересобирает APK.
4. Ошибка сборки — присылается лог из Actions, ассистент правит.
   Архивы — целые файлы, не git-диффы: при загрузке файлы заменяются целиком.
